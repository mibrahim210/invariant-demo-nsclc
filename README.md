# invariant-demo-nsclc

A small ML project on a fully synthetic, NSCLC-inspired imaging benchmark: paired CT-like / PET-like
2D phantoms, a simulated binary phenotype, and a CPU nearest-neighbor classifier with full run
provenance. It is the sample project reviewed by Invariant (the separate `invariant` repository), a code-review tool for ML
correctness.

**Data statement.** All patients, identifiers, images and labels are fictional and procedurally
generated by `demo_repo/data_gen.py`. No real patient data, personal information, client data,
social-media data or public datasets are used. This is not a clinical model and makes no clinical
claim. See `docs/dataset_card.md`.

## Layout

| Path | Purpose |
|---|---|
| `docs/study_protocol.md` / `.pdf` | Study protocol and its invariants (PDF built from the Markdown) |
| `docs/dataset_card.md` | Dataset card |
| `docs/release_record.md` | Generated record of the frozen release and every measured run |
| `configs/data_generation.json` | Frozen generation and experiment specification |
| `demo_repo/` | Generator, dataset loading, split, training |
| `tests/` | Baseline test suite |
| `run_artifacts/` | Durable per-run manifests and sweep summaries |
| `invariant.toml` | Invariant check configuration |

## Setup and commands

Requires [uv](https://docs.astral.sh/uv/). The interpreter is pinned by `.python-version`.

```bash
uv sync --locked
uv run --locked python -m demo_repo.data_gen --materialize   # regenerate arrays, verify against the manifest
uv run --locked pytest -q
uv run --locked python -m demo_repo.train                    # seeds 0-4, writes run_artifacts/
uv run --locked python scripts/write_release_record.py       # refresh docs/release_record.md
uv run --with reportlab==4.4.4 python scripts/build_protocol_pdf.py --check
```

Every number reported anywhere for this project comes from `run_artifacts/` and is listed with its run
ID in `docs/release_record.md`.

## Invariant scope

Invariant checks protocol INV-1 (patient independence). INV-2 (train-only fitting) and INV-3
(inference consistency) are reported as `not_checked`.
